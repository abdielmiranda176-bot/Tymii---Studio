A little about the studio

Small details.
Lasting impact.

Tymii Studio is an independent graphic design brand inspired by fashion editorials, print magazines, and the imaginative worlds built by online communities.

My approach is simple: balance expressive typography with clean composition, create a clear visual hierarchy, and make every design feel intentional.

This portfolio will grow with each new project. For now, the gallery features concept work that demonstrates the direction and style of the studio.
